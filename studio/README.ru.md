# AI-Word — установка на сервер

Текстовый редактор в браузере, устроенный как Microsoft Word: лента, стили, списки, таблицы, колонтитулы,
оглавление, рецензирование, документы .docx (а также .doc, .odt, .rtf). Со встроенным помощником на вашей
локальной модели и документами на вашем сервере.
На сервере нужны только **nginx + PHP + Ollama** — то, что у вас уже есть. Ничего компилировать не нужно.
Редактор полностью автономный: всё загружается из его папки, интернет и сторонние сайты не нужны.

## Установка (5 минут)

1. **Скачайте готовую сборку.** GitHub → репозиторий `ai-word` → справа **Releases** →
   верхняя «Сборка N — дата» (с пометкой Latest) → файл `ai-word-build-N-ГГГГ-ММ-ДД.zip`.
   Какая сборка стоит у вас, видно в шапке панели помощника: «Модель: … · сборка N».
2. **Распакуйте** — внутри одна папка `ai-word`.
3. **Положите её на сервер** рядом с остальными приложениями: `/app/src/ai-word/`.
   Папку можно назвать как угодно — все пути внутри относительные. Помощник и хранилище сами найдут
   ваш `auth.php` на два уровня выше и через него — `config.php`, `.env`, адрес Ollama и модель.
4. **Папка для документов создаётся сама**: `storage/ai-word` рядом с корнем сайта
   (на диске `/var/www/dwr/storage/ai-word`). Проверка: `https://ваш-домен/ai-word/api/files.php` → `{"ok":true,…}`.
5. **nginx** — готовые блоки в `nginx.conf.example` (большие запросы и долгое ожидание модели).
6. **Откройте** `https://ваш-домен/ai-word/`.

Обновление — то же самое: скачать новый zip и заменить папку (свой `studio/config.js` сохраните).
Если заливаете по FTP, лучше включить «Перезаписывать всегда».

## Чтобы документы выглядели точно как в Word

Word расставляет строки и страницы по размерам букв шрифта. Поэтому в AI-Word:

- **Шрифты-двойники уже внутри** (папка `fonts/`): Liberation Serif — по размерам Times New Roman,
  Liberation Sans — Arial, Liberation Mono — Courier New, Carlito — Calibri, Caladea — Cambria.
  Строки и переносы с ними совпадают с Word.
- **Шрифты организации — точь-в-точь.** Положите в `storage/ai-word/fonts/` (папка создаётся сама,
  рядом с папками пользователей) шрифты, на которые у организации есть лицензия, — например
  `times.ttf`, `timesbd.ttf`, `timesi.ttf`, `timesbi.ttf`, `arial*.ttf`, `calibri*.ttf` из `C:\Windows\Fonts`.
  AI-Word загрузит их у всех пользователей и будет верстать ими, а не двойниками.
- В Chrome и Edge можно взять шрифты самого компьютера: список шрифтов на ленте › «Загрузить установленные системные шрифты…».

## Документы

- **Ctrl+S** сохраняет документ в «Мои документы» на сервере (значок папки в панели помощника).
  Первый раз спросит имя, дальше сохраняет туда же. «Сохранить как…» — копия под новым именем.
- **Мои документы**: список с датой и размером, поиск, открыть, переименовать, удалить (в корзину `.trash`),
  «С компьютера…» — открыть .docx/.doc/.odt/.rtf с компьютера.
- У каждого пользователя своя папка. Документ с сервера сохраняется туда сам раз в минуту, если в нём есть изменения.
  Если сохранить не удалось (нет связи), копия остаётся в браузере, и панель предложит её открыть.
- «Файл › Экспорт» — PDF и другие форматы скачиваются в браузере.

## Помощник

- **Совет** — объясняет, где найти функцию, пересказывает документ, проверяет текст и оформление. Ничего не меняет.
- **Сделай** — сам правит: пишет и переписывает текст, оформляет по ГОСТ (поля, шрифт, интервал 1,5, отступ 1,25 см),
  ставит стили и заголовки, номера страниц, оглавление, таблицы. Каждое действие отменяется (Ctrl+Z).
- **Быстрые задачи** (значок с квадратиками): оформление по ГОСТ, интервалы, отступы, поля, номера страниц,
  оглавление в одно нажатие и готовые просьбы помощнику (проверить по методичке, пересказать, служебная записка…).
- Значения «по ГОСТ» — в `studio/config.js` (`gost`): поправьте под свою методичку.
- **Быстрая строка — Ctrl+Shift+Пробел.**

### ИИ у выделения

Выделите текст — рядом с мини-панелью форматирования появится кнопка **ИИ**. То же меню есть в контекстном
меню (правая кнопка → **ИИ-помощник…**) и открывается у курсора по **Ctrl+Alt+Пробел**. В меню:
улучшить, исправить ошибки, переформулировать, упростить, сократить, развернуть; официально-деловой,
научный, разговорный стиль; перевод; краткое содержание, тезисы, объяснение, вопросы; проверка орфографии,
стиля, логики; список, таблица, шаги; продолжение текста. В строке сверху можно написать свою просьбу
(«сделай вежливее», «добавь ссылку на приказ») и нажать Enter.

Модель видит весь документ, а меняет только выделенное (большой документ передаётся частями: начало,
оглавление и текст вокруг выделения). Ответ сначала показывается в окошке: **Заменить выделенное**,
**Вставить ниже**, **Копировать** или **Ещё вариант**. Вставленный текст принимает оформление документа
(шрифт, кегль, интервалы), списки и таблицы вставляются списками и таблицами. Отмена — Ctrl+Z.
Задания для модели — в `api/context.php`.

## Настройки в `.env` (необязательно)

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `AI_WORD_DATA_DIR` | Где хранить документы и шрифты организации | `storage/ai-word` рядом с корнем сайта |
| `AI_WORD_MODEL` | Модель помощника (нужны tools; для «глаза» — картинки) | `GLOBAL_MODEL` |
| `AI_WORD_OLLAMA_URL` | Адрес Ollama или шлюза | `OLLAMA_IP:OLLAMA_PORT` |
| `AI_WORD_CONTEXT` | Размер контекста | `GLOBAL_MODEL_CONTEXT` или 32768 |
| `AI_WORD_TIMEOUT` | Сколько секунд ждать модель | 180 |
| `AI_WORD_MAX_TOKENS` | Длина ответа | 2048 |
| `AI_WORD_AUTH_FILE` | Путь к `auth.php`, если папка лежит не в `/app/src/` | ищется автоматически |
| `AI_WORD_TALERS_FILE` | `talers.php` кабинета для ИИ у выделения (цена операции и остаток) | `cabinet/talers.php` рядом с корнем сайта, если он есть |
| `AI_WORD_ALLOW_ANON` | `1` — без входа (только для проверки!) | выключено |

## Если что-то не работает

| Признак | Что проверить |
|---|---|
| Редактор не запускается | Под полосой загрузки написано, какой файл не пришёл и почему |
| После заливки по FTP — старая версия | Программа заливки пропустила файлы того же размера: включите «Перезаписывать всегда» |
| В панели «Нужно войти в систему» | Вход в вашу систему в этом же браузере и на этом же домене |
| «Не удалось создать папку для файлов» | Создайте `storage/ai-word` и дайте PHP право записи, или задайте `AI_WORD_DATA_DIR` |
| Ошибка 413 / 504 | `client_max_body_size` / `fastcgi_read_timeout` — см. `nginx.conf.example` |
| Документ свёрстан не так, как в Word | Положите шрифты документа в `storage/ai-word/fonts/` и обновите страницу |

## Для разработчика

- Сборку делает GitHub Actions (`.github/workflows/studio.yml`) на каждое изменение ветки `main`.
- Мост редактора: `apps/wordcraft-web/src/web/bridge.rs` — `window.aiword.request(метод, параметры)`,
  те же методы, что у канала управления (`crates/ui-egui/src/control.rs`). В консоли браузера:
  `await aiword.execute('text.insert', {text: 'Привет'})`.
- Сохранение на сервер: `Services::save_to_page` → событие `aiword:save` → `api/files.php`.
