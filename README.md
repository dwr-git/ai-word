# AI-Word

Текстовый редактор в браузере, устроенный как Microsoft Word, с помощником на вашей локальной модели и
документами на вашем сервере. Ставится папкой на сервер с nginx и PHP: инструкция — [`studio/README.ru.md`](studio/README.ru.md),
что нового — [`studio/CHANGES.ru.md`](studio/CHANGES.ru.md). Готовые сборки — в Releases.

Основано на [WordCraft](https://github.com/storytold/wordcraft) (MIT OR Apache-2.0); описание исходного проекта —
[`docs/README-upstream.md`](docs/README-upstream.md), лицензии — [`NOTICE`](NOTICE).
